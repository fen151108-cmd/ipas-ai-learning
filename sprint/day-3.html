  • 辨認 KNN、樹、SVM、神經網路、Q 表、DQN 與自編碼器的核心機制

一、必讀位置：一條不洩漏的建模主線

建模流程是定義任務 → 準備特徵與標籤 → 先切分資料 → 只用訓練集擬合前處理與模型 → 用驗證集選方案 → 凍結後以測試集驗收。特徵是輸入線索，標籤是訓練時已知的目標，參數是模型從資料學到的內部數值；學習率或樹深等通常是超參數。

同一欄位的角色取決於任務與可取得時間。預測當下尚未發生的結果不能偷放進特徵，否則形成資料洩漏。

  • 訓練集用來學；驗證集用來選；測試集最後驗收。
  • 前處理參數也只能從訓練集學。

二、必讀前處理：One-hot、標準化、選特徵與 PCA

One-hot 把沒有自然順序的類別拆成多個指示欄，避免代碼製造假大小。標準化調整數值尺度，對距離或梯度敏感的方法尤其重要；驗證、測試與上線資料沿用訓練集得到的參數。

特徵選擇保留部分原欄位，PCA 則把原特徵線性組合成較少新軸。PCA 是特徵提取與降維，不會自動提供群號，也未必提升每個任務。

  • One-hot 處理名目類別的表示。
  • 標準化改尺度；PCA 改座標與維度。

三、必讀模型控制：L1、L2 與損失函數

L1 對係數絕對值加罰，常使部分係數成為零而形成稀疏解；L2 對係數平方加罰，通常讓多個係數平滑縮小。線性模型常見的 L1 懲罰本身是凸的，不能因為係數會歸零就誤說成非凸；也不能把零係數當成因果證明。

MSE 衡量連續值預測與真值的平方誤差，常用於迴歸；交叉熵比較分類機率與真實類別，對自信卻錯誤的分類給較大代價。先看目標型態，不是看模型名字選損失。

  • 標準化處理輸入尺度，正則化控制模型複雜度。
  • MSE 對迴歸；交叉熵對分類機率。

四、必讀常見模型：由核心機制辨認

KNN 對新樣本找最近的 K 個訓練樣本；分類用多數決，迴歸可取平均或中位。決策樹以特徵條件逐層切分，直觀但單棵樹可能過擬合。SVM 尋找能拉大類別間隔的邊界，核方法可處理非線性。神經網路以多層權重和非線性轉換學複雜表示。

沒有單一模型永遠最好。資料量、尺度、非線性、可解釋性、延遲與維護成本都會影響選擇，最後仍要用一致評估流程比較。

  • KNN 依鄰居；樹依切分；SVM 依最大間隔；神經網路依多層表示。
  • KNN 易受尺度影響。

五、延伸辨認：Q 表、Q-learning、DQN 與自編碼器

先用「機器人走迷宮」串起三個名詞：狀態是機器人目前的位置，行動是上、下、左、右，獎勵是到出口得 +10、撞牆得 −1。Q 值不是眼前立刻拿到的分數，而是「在這個狀態做這個行動，長期來看有多值得」。

  1. Q 表（存答案的表格）：每列是一個狀態，每欄是一個行動，格子裡記錄 Q 值；通常選同一列中 Q 值最大的行動。
  2. Q-learning（更新答案的方法）：先行動、看到獎勵與下一個狀態，再修正原本的 Q 值。可記成：「舊估計」往「眼前獎勵＋下一步最佳可能」靠近。
  3. DQN（表格太大時的替代工具）：當狀態是遊戲畫面或感測器等高維資料，Q 表列不完，就用深度神經網路接收狀態，一次估計各行動的 Q 值。

三者關係：Q 值是要學的「行動價值」；Q-learning 是更新 Q 值的規則；Q 表與 DQN 是保存或估計 Q 值的兩種方式。因此不是 Q-learning 與 DQN 二選一，而是 DQN 把 Q-learning 的表格換成神經網路。

一秒判斷：少量離散狀態、每種情況列得出來 → Q 表；狀態太多、連續或是影像，列不完 → DQN。兩者都靠「狀態→行動→獎勵→新狀態」反覆試錯，不需要老師逐筆提供正確動作標籤。

一般自編碼器以輸入本身作重建目標，透過編碼器壓縮、解碼器重建。做異常偵測時通常用正常資料訓練，讓正常樣本重建較好，再以重建誤差輔助找異常；若把異常也大量混入，模型可能連異常都學會重建。

  • Q 值＝某狀態下採取某行動的長期價值。
  • Q-learning＝用獎勵與下一狀態修正 Q 值的方法。
  • Q 表＝明列每格數值；DQN＝用神經網路近似數值。
  • 自編碼器重建輸入，不代表自動知道業務異常。

六、必讀評估：不平衡資料先定義正類

Precision 問模型判為正的案例中有多少是真的，重視誤報；Recall 問實際正類中有多少被抓到，重視漏報；F1 是兩者的調和平均，任一很低都會拖累結果。類別嚴重不平衡時，Accuracy 可能被多數類撐高。

先定義正類，再依錯誤代價選指標。漏掉真正風險代價高時優先關注 Recall；每次誤報都很昂貴時優先關注 Precision；兩者都重要可看 F1 與完整混淆矩陣。

  • Precision 管誤報；Recall 管漏報。
  • F1 不直接使用真陰性，不能取代完整判讀。

七、完整案例：維護預警從欄位到驗收

某設備團隊以溫度、振動、負載與機型預測近期是否異常。機型先做 One-hot，數值尺度只用訓練集擬合；候選方案在驗證集比較。若要找鄰近狀態可試 KNN，若重視規則可試樹，若資料邊界適合可試 SVM，複雜感測訊號可評估神經網路。

目標是異常類別時可用交叉熵；若改預測剩餘時數則可用 MSE。異常少且漏報代價高時，主看 Recall 並同看 Precision。方案凍結後才在測試集報告泛化表現。

  • 前處理、模型、損失與指標要對準同一任務。
  • 測試結果不應再被拿來反覆調參。

八、陷阱與遷移：本日不要求數學推導

初級衝刺先會辨認概念、流程與情境，不要求推導最佳化公式。延伸名詞的目標是看懂題幹：Q 表與 DQN 的表示差異、自編碼器的重建邏輯、L1 與 L2 的效果傾向。

本課測驗為原創理解題，不是官方考題，也不預測命題。作答時依序問：目標是什麼、資料怎麼表示、哪份資料可用、模型怎麼學、錯誤代價是什麼。

  • L1 常產生零係數，不等於 L1 是非凸。
  • 高 Accuracy 不保證少數正類有被抓到。
  • PCA 新軸不是直接保留的原欄位。

選讀補強｜看懂深度模型與驗證，不必先推導公式

CNN 善於擷取影像空間特徵；RNN 利用序列狀態處理前後依賴，LSTM 以閘門改善長期資訊保存，但不是保證永不遺忘。神經網路先前向計算預測，再依損失反向傳播梯度，最佳化器更新參數；學習率太大可能震盪，太小可能進展緩慢。Batch Normalization 作用在網路內部表示，並不等於原始欄位的 Z-score 前處理；Dropout 是訓練時隨機停用部分單元的正則化方法。

RNN — Recurrent Neural Network｜循環神經網路
依序處理資料，以狀態承接前文；基本 RNN 較難學到長距離依賴。
LSTM — Long Short-Term Memory｜長短期記憶網路
常見 RNN 變體，以記憶單元與閘門控制資訊保留、遺忘及輸出。
GRU — Gated Recurrent Unit｜閘控循環單元
常見 RNN 變體，以更新閘與重置閘控制序列資訊，結構通常比 LSTM 精簡。

以殘差連接讓輸入與轉換結果相加，幫助深層網路訓練；不是 RNN 變體，也不是序列記憶單元。

下載完整圖卡回到選讀補強

先理解梯度：模型預測錯了，誤差會從輸出端一層一層往回傳，告訴每層參數「要往哪個方向、調整多少」。這個調整訊號就是梯度。可以把深層網路想成十個人排隊傳話：最後一個人發現答案錯了，要把修正訊息一路傳回第一個人。

  1. 梯度消失：訊號每經過一層都只剩一小部分，例如每層乘上 0.1；傳十層後變成 0.110，前面幾層幾乎收不到修正訊息。結果是靠近輸入端的參數幾乎不更新，模型學得很慢，RNN 也難以記住很久以前的資訊。
  2. 梯度爆炸：訊號每經過一層反而被放大，例如每層乘上 2；傳十層後變成 210。參數一次被改得太大，訓練可能劇烈震盪，損失突然變很大，甚至出現 NaN 而無法繼續。

生活化比喻：十個人依序調整音量。每人都把聲音調成前一人的一半，最後幾乎聽不到，就是梯度消失；每人都把音量加倍，最後爆音失控，就是梯度爆炸。兩者都發生在反向傳播的修正訊號，不是指模型的預測值本身消失或爆炸。

常見改善：ReLU、合適的權重初始化、Batch Normalization、LSTM／GRU 或殘差連接可幫助梯度傳遞；遇到梯度爆炸常用 gradient clipping 限制梯度大小。考題看到「前層學不到、長期資訊留不住」先想梯度消失；看到「更新劇烈、損失暴增或 NaN」先想梯度爆炸。

一般 k-fold 將資料分折輪流驗證，有助檢查表現波動，但資料具有時間或同一個體群聚時，不能盲目隨機切分。需要重現隨機切分時，可固定隨機種子，並保存資料與程式版本。類別不平衡可考慮權重、抽樣或 SMOTE，但只能在訓練資料內處理；合成資料仍需檢查合理性。

Precision＝TP／(TP＋FP)，看抓出的正類有多少是真的；Recall＝TP／(TP＋FN)，看真正正類找回多少。F1 是兩者的調和平均；Accuracy 看全體答對比例，少數類極少時可能誤導。閾值降低通常能提高召回、也可能增加誤報，應依漏報與誤報代價在驗證資料選擇，而非反覆調整到測試集高分。

  • 只需認得機制與情境；遇到數值題再按公式核算，不以模型名稱猜任務。

相近名詞，真正差在哪？

特徵 ／ 標籤

特徵是模型輸入線索；標籤是監督式訓練要學會預測的答案。

參數 ／ 超參數

參數由訓練資料學得；超參數由流程設定或以驗證資料選擇。

One-hot ／ 標準化

前者把名目類別轉成指示欄；後者調整數值尺度。

特徵選擇 ／ PCA

前者保留部分原欄位；後者建立原特徵組合成的新軸。

L1 ／ L2

L1 常導致稀疏與零係數；L2 通常整體平滑縮小。

Q 表 ／ DQN

Q 表明列狀態—行動值；DQN 用神經網路近似 Q 值。

MSE ／ 交叉熵

MSE 常對連續值迴歸；交叉熵常對分類機率。

Precision ／ Recall

Precision 以預測為正為分母、關注誤報；Recall 以實際為正為分母、關注漏報。

換個產業，還能用同一個邏輯嗎？

表單含地區類別、金額與件數，要預測處理分鐘。

地區無自然順序可 One-hot；數值可視模型需要標準化；目標是連續分鐘，屬迴歸並可用 MSE。

影像系統只有正常品的大量資料，要找少見異常。

可用正常資料訓練自編碼器重建一般模式，再以重建誤差作異常線索；門檻與效果仍須用驗證資料確認。

控制系統狀態數量可列舉，之後擴充到高維感測輸入。

小型可列舉狀態可用 Q 表；高維狀態可考慮 DQN 近似 Q 值，但仍須處理探索、穩定訓練與獨立評估。

這些是要避開的錯誤說法

  • 先用全資料擬合標準化或 PCA，會讓驗證與測試資訊洩漏。
  • One-hot 欄位的零與一是指示狀態，不代表大小關係。
  • L1 常使係數歸零，但不能因此宣稱 L1 正則化是非凸。
  • PCA 是降維，不等同特徵選擇，也不會自動分群。
  • KNN 的 K 是鄰居數；K-means 的 K 是群數。
  • 自編碼器異常偵測通常以正常資料學重建，異常門檻仍需驗證。
  • Accuracy 高可能只是猜中多數類；不平衡時要看 Precision、Recall、F1 與混淆矩陣。
  • 測試集若反覆參與調參，就不再是獨立的最後驗收。

以上是誤區，不是正確結論；請用前面的對照說明它為什麼不成立。
