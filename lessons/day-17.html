強化學習與半監督式學習

半監督式用「少量標記＋大量未標記」學預測；強化學習用「行動＋環境回饋」學策略。

兩者都不是單純的監督式或非監督式，但混合的東西不同：半監督式混合兩種標記狀態；強化學習串起狀態、行動與延後回饋。

一、先定位：同在「學習方式」，判斷訊號卻不同

機器學習›依訓練方式辨認›標記組成？／互動回饋？›模型或策略

上位概念是機器學習的訓練方式。半監督式的相鄰概念是監督式與非監督式：它同時使用少量已標記樣本與較多未標記樣本。強化學習則以代理和環境互動、累積獎勵與行動策略為核心。官方指引將強化學習和監督式、非監督式並列，強調回饋、試錯與長期規劃。[2]

前置先分清標籤、未標記資料與非監督探索
本課少量標記學預測；環境回饋學策略
後續訓練、驗證、測試與泛化評估
TWO LEARNING SIGNALS

二、先看「學習訊號」，不要只看資料多不多

LABEL MIX半監督式｜標記不足，但仍有一小部分答案

把少量已標記樣本和大量未標記樣本放進同一學習流程，希望利用未標記資料呈現的分布結構，改善對新樣本的預測。

典型輸出：類別或數值預測
INTERACTION LOOP強化學習｜答案不是逐筆標籤，而是行動後的回饋

代理觀察環境狀態、選擇行動、收到獎勵與下一狀態，再調整策略，追求長期累積回報。

典型輸出：在各種狀態下怎麼行動的策略

scikit-learn 1.9.1 文件把半監督式描述為訓練資料中只有部分樣本有標記，尤其適合少量標記點與大量未標記點的情境；但演算法必須對資料分布作出假設，不能保證未標記資料一定有幫助。[4]

最快判斷句題幹出現「少量人工標記＋大量未標記」先想半監督式；出現「代理、環境、行動、獎勵、反覆互動」先想強化學習。
SEMI-SUPERVISED LEARNING

三、半監督式：未標記資料不是答案，而是額外結構

少量 LABELED有特徵 X，也有標籤 y

例如少數時段由使用者確認為「舒適」或「不舒適」。

＋
大量 UNLABELED只有特徵 X，沒有標籤 y

例如大量溫度、濕度、能耗與時段紀錄，未逐筆確認感受。

→
ONE MODEL利用兩者訓練預測模型

目標仍是對新資料做分類或其他預測，不是只把資料分群。

一種常見路徑是自我訓練：先用已標記資料建立分類器，再對未標記樣本預測，挑選符合條件的預測加入下一輪訓練；另一類是標籤傳播，依樣本相似圖把標籤資訊傳向未標記樣本。[4]

關鍵假設資料中的相近或同一結構樣本，標籤也傾向一致。若假設不成立錯誤的偽標籤或不相干的未標記資料，可能把錯誤放大。

因此，「有更多未標記資料」不是自動加分。必須檢查資料是否來自相近分布、少量標記是否可靠且具代表性，以及加入未標記資料後的驗證表現。

四、強化學習：一次好回饋，不等於長期好策略

STATE狀態目前環境可觀察到的情況
→
AGENT代理根據策略選擇下一個行動
→
ACTION行動對環境採取可選操作
→
FEEDBACK獎勵＋下一狀態環境回傳結果，代理再調整策略
↺

官方指引指出，強化學習讓代理透過環境互動學習行動策略，方向是取得最大的累積回報，尤其適合試錯與長期規劃任務。[2]

眼前獎勵當下立刻得到的分數

把設備全部關閉可能立刻省電，但舒適度會快速下降。

累積回報一段時間內結果的總和

策略要權衡接下來多個時段的舒適、能耗與設備切換。

獎勵是設計給代理的學習訊號，不等於每個狀態的正確答案標籤。若獎勵函數只獎勵省電，系統可能學到犧牲舒適的捷徑；因此獎勵設計、限制條件、安全測試與人工監督都不能省略。

ONE SCENARIO, TWO PATHS

五、貫穿情境：同一個家庭節能目標，兩條不同學習路徑

家庭希望系統兼顧舒適與節能。資料包含室內溫度、濕度、時段、設備狀態與能耗；只有少數時段有人確認舒適度。

PATH A｜半監督式補強「舒適／不舒適」預測
  1. 少量時段有人工確認標籤
  2. 大量時段只有感測特徵
  3. 利用兩者訓練分類模型
  4. 在保留驗證資料上比較是否真的改善
問題：這個時段較可能屬於哪個類別？
PATH B｜強化學習學會「現在該怎麼調整」
  1. 觀察目前室內狀態
  2. 選擇維持、調高或調低設定
  3. 收到舒適與能耗組成的獎勵
  4. 經反覆互動更新長期策略
問題：在這個狀態下，採取哪個行動較好？
同一專案可以串接半監督式模型可先估計舒適類別，估計結果再成為決策系統的部分狀態；但「預測狀態」與「選擇行動」仍是兩個不同問題。

DO NOT CONFUSE

七、七組容易混淆處與 iPAS 判斷訊號

  1. 半監督式 ≠ 半套監督式：「半」指已標記與未標記樣本並用，不是模型只訓練一半。
  2. 偽標籤 ≠ 人工真實標籤：偽標籤是模型預測後暫時採用的結果，可能把錯誤帶進下一輪。
  3. 未標記越多 ≠ 一定越準：若資料分布不同、標記偏誤或演算法假設不成立，額外資料可能無助益。
  4. 強化學習 ≠ 一般分類：分類預測類別；強化學習在狀態中選行動並考慮後續結果。
  5. 獎勵 ≠ 標籤：獎勵評價行動後果，不是告訴每個狀態唯一正確動作。
  6. 最高立即獎勵 ≠ 最佳策略：題目出現延後效果或長期規劃，要看累積回報。
  7. 試錯 ≠ 可在真實環境任意冒險：高影響情境仍要模擬、安全限制、監控與人工問責。

八、iPAS 五問判斷法

01題目提供的是標籤，還是行動後的獎勵？
02資料是全部有標記、全部無標記，還是少量有標記？
03目標是預測類別／數值，還是學會行動策略？
04是否出現代理、環境、狀態、行動與累積回報？
05結果是否以保留資料或安全互動環境驗證？

理解測驗

先作答再看解析。題目是本站原創理解題，不冒充官方試題。

1. 店家只有 300 筆人工標記的查詢類別，另有 30,000 筆未標記查詢，希望改善分類器。最符合哪種學習方式？
2. 下列哪一組詞最直接指向強化學習？
3. 自我訓練把高信心預測加入下一輪訓練。對這些「偽標籤」最合理的理解是什麼？
4. 節能代理有兩個行動：立刻關閉設備可得短期高分，但之後舒適度大幅下降；平緩調整短期分數較低，長期較穩定。應優先比較什麼？
5. 團隊加入大量未標記資料後，半監督式模型反而變差。下列哪個處理最合理？
6. 家庭系統先估計「舒適／不舒適」，再根據狀態選擇設備調整。哪個說法最正確？
