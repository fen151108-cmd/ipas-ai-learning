非監督式學習

沒有目標標籤，不是沒有目標：非監督式學習從未標記資料找結構，不是在預測既定答案。

昨天用標籤型態分清分類與迴歸；今天先把標籤拿掉，觀察演算法如何依特徵中的相似、變化與罕見程度，提出可供解讀的資料結構。

Day 15約 40–60 分鐘概念統整＋店家備貨情境＋6 題測驗＋Podcast
KNOWLEDGE MAP

一、先定位：依「訓練訊號」分類的另一條路

可用特徵 X›沒有目標標籤 y›非監督式學習›結構候選›解讀與驗證

上位概念是機器學習；下位任務包括分群、資料探索、特徵提取、降維與異常偵測。相鄰概念是使用已知標籤的監督式學習，以及依獎勵回饋學策略的強化學習。前置是特徵、資料品質與尺度；後續會進入 K-means、PCA，再回到訓練流程與模型評估。官方指引把監督式、非監督式與強化學習列為依訓練方式區分的方法。[2]

本課不靠目標標籤找結構
後續用 K-means 與 PCA 具體化
CORE DEFINITION

二、正確定義：沒有「事先標好的答案」

INPUT只有特徵 X

品項數、接單時段、待處理量、客製項目數……

＋
NO TARGET LABEL沒有目標 y

沒有預先提供「這筆屬於哪一群」的正確答案。

→
DISCOVERY找潛在結構

提出群組、低維表示、異常候選或其他模式。

非監督式學習無需使用事先標記好的訓練資料，而是從未標記資料發掘潛在模式、結構或分群；常見任務包括資料探索、特徵提取與資料降維。[2]

「非監督」真正拿掉的是什麼？拿掉的是逐筆目標答案，不是拿掉資料清理、特徵選擇、演算法設定、品質檢查或人的解讀。
THREE DISCOVERY LENSES

三、三種常見任務：群、軸、例外

GROUP分群 Clustering

依相似性讓組內較相似、組間較不同；輸出是群組配置，不是預先答案。

問：資料自然形成哪些群？
AXIS降維 Dimensionality Reduction

把許多特徵濃縮成較少的新維度，盡量保留重要資訊，方便呈現或後續分析。

問：能否用更少軸看主要變化？
EXCEPTION異常偵測 Anomaly Detection

找出偏離常見模式的資料點，作為待檢查候選；罕見不自動等於錯誤。

問：哪些資料和多數模式很不一樣？

官方指引另外將聚類分析描述為「組內相似度高、組間差異大」，將 PCA 說明為減少資料維度並保留大部分資訊，也把異常偵測定位為識別離群或罕見模式。[2]

ONE SCENARIO, THREE QUESTIONS

四、貫穿情境：沒有備貨標籤，仍可先探索訂單型態

店家累積了一批訂單紀錄，每筆都有品項數、接單時段、待處理量、客製項目數與包裝件數，但沒有「訂單類型」或「是否需要優先處理」的既定標籤。團隊先做探索，而不是假裝已有正確答案。

FEATURE SPACE未標記訂單資料
  • 品項數
  • 待處理量
  • 客製項目數
  • 包裝件數
分群找出相似訂單組合

可能出現「少品項、高客製」與「多品項、低客製」等型態；名稱是分析後才解讀。

降維把多個特徵濃縮成兩軸

用低維圖觀察主要變化與群組是否重疊，不把新軸硬說成原始欄位。

異常偵測找出罕見特徵組合

例如品項少但包裝件數特別高；先查紀錄與情境，不立刻刪除。

群組編號只是演算法輸出，例如第 0 群或第 1 群；它本身不等於「高價值」「急件」或任何正確標籤。命名與行動仍需回到資料分布、用途與風險。

主要訓練訊號逐筆特徵＋已知標籤未標記特徵中的結構行動後的獎勵與環境回饋

高頻陷阱「監督」不是逐筆盯著沒有標籤不等於沒有目標獎勵不等於類別標籤

官方指引以「帶有標記的訓練數據」描述監督式學習，以「未標記數據」描述非監督式學習，並以獎勵與環境互動描述強化學習。[2]

STRUCTURE IS NOT AUTOMATIC TRUTH

六、結果為何會變：特徵、尺度與設定都在定義「相似」

選哪些特徵比較什麼

用時段與品項數，和用客製數與包裝數，可能看見不同結構。

→
怎麼縮放距離誰主導

數值範圍很大的欄位，可能在距離計算中壓過其他欄位。

→
演算法設定想找哪種結構

群數、距離觀念與方法假設不同，輸出也可能改變。

→
解讀與驗證是否有用

檢查群內／群間差異、穩定性、可解釋性與實際用途。

因此，非監督式結果是「資料、特徵表示、方法與設定共同產生的結構候選」，不是資料自己宣告的唯一真相。下一課會用 K-means 的 K 值與 PCA 的新軸，把這件事具體拆開。

DO NOT CONFUSE

七、六組容易混淆處與 iPAS 判斷訊號

  1. 非監督式 ≠ 無人管理：題目出現「無標記資料、探索結構」才是核心訊號。
  2. 分群 ≠ 分類：分類的類別是訓練前提供的答案；分群的群組是分析後才形成。
  3. 群號 ≠ 類別標籤：0、1、2 只是群組識別，不代表優劣、順序或真實類別。
  4. 異常 ≠ 錯誤：異常點可能是輸入錯誤，也可能是罕見但有效的事件，需查原因。
  5. 降維 ≠ 任意刪欄：降維通常建立較少的新表示；不能直接假設新軸等於某個原始欄位。
  6. 沒有標籤 ≠ 沒有設定：仍要選特徵、處理尺度、設定方法並驗證結果。

理解測驗

先作答再看解析。題目是本站原創理解題，不冒充官方試題。

1. 訂單資料沒有「類型」標籤，系統依品項數、時段與客製數找出三個相似群組。這是什麼？
2. K-means 輸出第 0 群、第 1 群、第 2 群。最正確的解讀是哪一項？
3. 團隊想把十個訂單特徵濃縮成兩個新軸，以便觀察主要變化。最接近哪一種任務？
4. 異常偵測標出一筆「少品項但包裝件數很高」的訂單。下一步最合理的是什麼？
5. 同一批訂單改用不同特徵組合與縮放方式後，分群結果改變。最合理的說明是什麼？
6. 「非監督式學習」最正確的意思是哪一項？
