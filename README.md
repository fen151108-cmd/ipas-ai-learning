# iPAS AI 概念統整學習站

以 iPAS AI 應用規劃師初級能力鑑定為範圍，採「完整知識地圖 → 每日核心概念 → 關係與辨析 → 中性生活情境 → 測驗與 Podcast」的方式整理。

## 內容政策

- 公開內容完全去個人化
- 不含任何個人、夥伴或公司名稱
- 案例採中性生活情境
- 以官方學習指引、樣題與勘誤為依據
- 每課有獨立網址、前後跳頁、原創理解測驗與 Podcast
- 網站題目不是官方考題

- Day 06：結構化、半結構化、非結構化
- Day 07：資料品質：缺失、錯誤、重複、離群
- Day 08：ETL：擷取、轉換、載入
- Day 09：平均數、中位數、標準差與分布
- Day 10：資料視覺化如何選圖
- Day 11：資料隱私、安全、權限與去識別
- Day 12：特徵、標籤、參數與輸出
- Day 13：監督式學習
- Day 14：分類與迴歸
- Day 15：非監督式學習

- Day 18：訓練、驗證、測試流程

首頁與每一課頂端提供已發布課程的常駐選課按鈕；每課另有前後跳頁、概念地圖、比較表、中性生活案例、原創理解測驗與 Podcast。
