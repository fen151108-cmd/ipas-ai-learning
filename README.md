# iPAS AI 概念統整學習站

以 iPAS AI 應用規劃師初級能力鑑定為範圍，採「完整知識地圖 → 每日核心概念 → 關係與辨析 → 中性生活情境 → 測驗與 Podcast」的方式整理。

## 內容政策

- 公開內容完全去個人化
- 不含任何個人、夥伴或公司名稱
- 案例採中性生活情境
- 以官方學習指引、樣題與勘誤為依據
- 每課有獨立網址、前後跳頁、原創理解測驗與 Podcast
- 網站題目不是官方考題

## 目前課程

- Day 01：AI 的定義、範圍與邊界
- Day 02：分析型、預測型、生成型 AI
- Day 03：AI 治理為什麼從設計開始
- Day 04：風險分級、透明與人工問責
- Day 05：資料、紀錄、樣本與來源

首頁與每一課頂端提供 D1～D5 常駐選課按鈕；每課另有前後跳頁、概念地圖、比較表、中性生活案例、原創理解測驗與 Podcast。

## 進度保存

完成狀態使用 `localStorage`，只保存在目前瀏覽器；尚未啟用帳號或跨裝置同步。
